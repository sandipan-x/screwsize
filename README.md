# ScrewSize

Metric to imperial screw size chart: convert M3–M10 and #4–#14 screws, with thread diameters, pilot-hole drill bits, and head-type guide. Free tool.

## Features
- Metric M3–M10 ↔ imperial #4–#14 conversion both ways
- Diameter plus recommended pilot-hole drill size for every size
- Head-type guide (flat, pan, round, oval, hex) built into results
